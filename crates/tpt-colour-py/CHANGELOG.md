# Changelog

All notable changes to `tpt-colour-py` are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The crate is not published, so its version
tracks the workspace.

## [Unreleased]

### Added

- Python bindings through PyO3, built as an `abi3` wheel for Python 3.9 and later. They cover
  parsing, contrast, vision simulation, harmonies and the `Manager` profile registry.
- Tests: nine `unittest` checks that run against the installed wheel.

## [0.1.0]

Initial workspace release. The crate was unpublished at this point.
