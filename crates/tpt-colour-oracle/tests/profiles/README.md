# Official ICC profiles used as oracle inputs

- `sRGB2014.icc`: ICC v2 sRGB, from https://registry.color.org/rgb-registry/srgbprofiles
- `sRGB_v4_ICC_preference.icc`: ICC v4 sRGB (colorspace class), from the same page

The ICC states that its profiles "may be copied, distributed, embedded, made, used, and sold
without restriction" where the ICC is the owner. See https://registry.color.org/profile-library/.
They are unmodified copies, kept here so the oracle tests run without a profile directory.
