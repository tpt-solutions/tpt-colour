# tpt-colour-oracle

Test-only checks that compare [tpt-colour](https://github.com/tpt-solutions/tpt-colour) with
LittleCMS, the reference colour management engine.

This crate is never a dependency of a shipped crate, and it is not published. It needs no C
toolchain. The LittleCMS results are stored as fixtures, generated by
`tools/oracle/generate_littlecms.py`, and the tests read those fixtures.

## Run

```sh
cargo test --manifest-path crates/tpt-colour-oracle/Cargo.toml
```

## What it covers

- Matrix/TRC and LUT transforms for several profiles: RSWOP CMYK, a gamma 1.8 RGB profile, the
  official v2 matrix and v4 LUT profiles, and the PRMG and ROMM profiles. The intents are
  perceptual and relative, and the device-side (B2A) direction is covered too.
- Known differences from LittleCMS, which the [ICC changelog](../tpt-colour-icc/CHANGELOG.md)
  records.

Profiles that tpt-colour writes are checked by a separate script,
`tools/icc/check_written_profiles.py`, which reads them with an independent CMM.
