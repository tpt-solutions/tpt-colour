# Changelog

All notable changes to `tpt-colour-capi` are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The crate is not published, so its version
tracks the workspace.

## [Unreleased]

### Added

- A C ABI for parsing, contrast, vision simulation and the `Manager` profile registry, with a header
  generated by `cbindgen` in `include/tpt_colour.h`.
- Tests: four Rust tests, and 13 `ctypes` checks against the built library.

Initial workspace release. The crate was unpublished at this point.
