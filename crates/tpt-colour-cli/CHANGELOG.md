# Changelog

All notable changes to `tpt-colour-cli` are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The crate is not published, so its version
tracks the workspace.

## [Unreleased]

### Added

- `tpt-colour cube`, which writes an Adobe `.cube` 3-D LUT to stdout.
- `tpt-colour doctor`, which reports multiProcessElements tables, missing descriptions and tags, and
  sRGB round-trip error.
- `tpt-colour info`, `convert` and `gamut-check`.

## [0.1.0]

Initial workspace release. The crate was unpublished at this point.
